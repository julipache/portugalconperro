# Portugal con Perro

Guía especializada para viajar por Portugal con perro: alojamientos realmente pet-friendly, destinos, playas, rutas y restaurantes.

## Objetivo

Construir una web SEO-first que no se limite a indicar si un alojamiento admite mascotas, sino que recoja información útil para viajar con perro: jardín privado, jardín vallado, número/tamaño de perros, suplementos, piscina, cercanía a playas y otros datos verificables.

## Estado

Proyecto en fase inicial. La primera versión se desarrollará con Astro y se preparará para desplegar en Vercel y conectar con Supabase.
